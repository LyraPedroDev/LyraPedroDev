### 💻 Sobre Mim

Sou um jovem autodidata e explorador tecnológico fascinado por **segurança cibernética**, **Linux** e **automação**. Adoro desmontar sistemas para entender profundamente como funcionam debaixo do capô e, a partir disso, construir soluções eficientes para problemas reais do dia a dia. 

Este repositório especial é o meu console de comando, onde compartilho os meus projetos, ferramentas de automação e meu aprendizado contínuo nas trincheiras do desenvolvimento backend e de infraestrutura.

- 🔍 **Foco atual**: Aprofundando estudos em hardening de sistemas Linux, arquiteturas de APIs com Flask e automação avançada com fluxos inteligentes.
- ⚙️ **Filosofia**: *"Se uma tarefa precisa ser feita manualmente mais de duas vezes, ela deve ser automatizada."*
